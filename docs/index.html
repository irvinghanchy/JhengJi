什麼是 Ideographic Tally Marks？

在東亞漢字文化圈中，人們習慣使用漢字「正」的五個筆劃來進行計數（每滿五劃形成一個完整的正字）。 Unicode 11.0 正式將此計數法納入「算籌數字」區塊（Counting Rod Numerals, U+1D360–U+1D37F）。

⌨️

雙模輸入支援

無需安裝複雜的輸入法或費力複製 SMP（第一輔助平面）罕見 Unicode。在日常情境下，只要套用本字型，直接鍵入數字 1、2、3、4、5 即會直接呈現為正字的一至五筆劃！

⚡

極致輕量化 (1.1 ~ 1.3 KB)

經過精準的字元子集裁剪，除了 10 個核心計數字符與空格外，清除其餘數萬漢字。單個 WOFF2 檔案僅約 1 KB，網頁載入瞬間完成，完全無懼頻寬壓力。

🎨

全字重宋體 + 楷書

提供由思源宋體精緻剖析的 7 種字重（極細 ExtraLight 至 特黑 Black），以及由全字庫正楷體重構的「正記體-楷體」，滿足印刷、海報、開票圖表等各式視覺設計需求。

💻 Webfont CSS 引入範例

在您的網頁 CSS 中加入以下 @font-face 設定即可輕鬆使用：

@font-face {
  font-family: 'JhengJi Song';
  src: url('fonts/JhengJiSong-Regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}

@font-face {
  font-family: 'JhengJi Kai';
  src: url('fonts/JhengJiKai-Regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}

/* 在欲使用正字計數的標籤套用 */
.tally {
  font-family: 'JhengJi Song', serif;
  font-size: 32px;
}

HTML 使用範例：

<!-- 輸入 12345 就會直接呈現 1~5 畫正字！ -->
<span class="tally">5553</span> <!-- 呈現為 3個正 + 1個3畫 (18) -->
<span class="tally">𝍲𝍳𝍴𝍵𝍶</span> <!-- 亦可使用標準 Unicode 字符 -->
